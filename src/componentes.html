Preparacao

Registre os componentes e importe os estilos e a fonte de icones.

Codigo

<link rel="stylesheet" href="https://unpkg.com/@mdi/font@7.4.47/css/materialdesignicons.min.css">
<link rel="stylesheet" href="https://unpkg.com/@betha-plataforma/estrutura-componentes/dist/estrutura-componentes/estrutura-componentes.css">

<script type="module" src="https://unpkg.com/@betha-plataforma/estrutura-componentes/dist/estrutura-componentes/estrutura-componentes.esm.js"></script>
A fonte Material Design Icons e obrigatoria para o bth-icone e para todo componente que exibe icones. Sem ela os icones aparecem como caixas vazias.
Container das ferramentas

As ferramentas renderizam um bth-menu-ferramenta internamente, que usa height: 100%. Por isso precisam de um container com altura definida. 

.barra {
  display: flex;
  align-items: center;
  height: 40px;
}
Autenticacao

Os componentes que consomem API recebem a autenticacao por propriedade, nunca por atributo, porque o valor e um objeto. Vale para bth-suporte, bth-novidades, bth-notificacoes e bth-marca-produto. 

const authorization = {
  getAuthorization() {
    return {
      accessToken: '...',
      accessId: '...',
      userId: '...',
      systemId: 78,
      userAccess: '...'
    };
  },
  handleUnauthorizedAccess() {
    // renove o token e resolva a promise
    return Promise.resolve();
  }
};
O painel lateral aberto pelas ferramentas usa position: fixed com top: 40px, medida herdada da barra horizontal do bth-app. Fora do shell o painel funciona, mas sempre ancora a 40px do topo da viewport.

Comuns

Componentes de uso geral. Nenhum depende do bth-app nem de autenticacao.

bth-icone

Icone da biblioteca Material Design Icons. E a base visual dos demais componentes.

  • Atributo icone, obrigatorio: o nome do icone sem o prefixo mdi-.
  • Atributos tamanho e cor, no mesmo formato de font-size e color. Por padrao herdam do contexto.
  • Atributo aria-label. Quando ausente, assume o nome do icone.

Codigo

<bth-icone icone="cloud"></bth-icone>
<bth-icone icone="cloud" tamanho="25px" cor="#f7932f"></bth-icone>
<bth-icone icone="cloud" tamanho="2rem" cor="#df4661" aria-label="Servico contratado"></bth-icone>

Resultado

bth-avatar

Representacao visual de uma pessoa ou entidade, a partir de imagem, iniciais ou icone.

  • Uma das tres fontes de conteudo: src, iniciais ou icone.
  • tamanho aceita menor, pequeno, medio ou grande. Use dimensao para um valor em pixels.
  • quadrado, borda, borda-tamanho, borda-raio e borda-cor controlam a forma.
  • sub-icone sobrepoe um indicador de status.
  • Emite imageLoadError quando a imagem de src falha. Nao ha fallback automatico: cabe ao host remover o src para o avatar cair nas iniciais ou no icone.

Codigo

<bth-avatar src="https://exemplo.com/foto.png"></bth-avatar>
<bth-avatar iniciais="Palavras Compostas"></bth-avatar>
<bth-avatar icone="cloud" sub-icone="check-circle" sub-icone-title="Ativo"></bth-avatar>
<bth-avatar iniciais="TX" tamanho="grande" quadrado></bth-avatar>
<bth-avatar icone="cloud" borda borda-tamanho="2px" borda-cor="#7FAADC"></bth-avatar>
<bth-avatar iniciais="TX" dimensao="64"></bth-avatar>

Fallback quando a imagem nao carrega:

<bth-avatar id="avatar" src="https://exemplo.com/foto.png" iniciais="TX"></bth-avatar>

<script>
  document
    .getElementById('avatar')
    .addEventListener('imageLoadError', (event) => {
      event.target.removeAttribute('src');
    });
</script>

<bth-loader></bth-loader>

bth-empty-state

Estado vazio ilustrado, para listas sem resultado ou falhas de conexao.

  • Atributo show controla a exibicao.
  • O tipo e escolhido por atributo: registros, registros-pesquisa, online, offline ou pagina-nao-encontrada.
  • pequeno reduz a ilustracao, para uso dentro de paineis.
  • O conteudo do slot padrao substitui a mensagem.

Codigo

<bth-empty-state show registros></bth-empty-state>

<bth-empty-state show offline pequeno></bth-empty-state>

<bth-empty-state show registros-pesquisa>
  Nenhum resultado para a busca informada.
</bth-empty-state>

Resultado

Tipos, em tamanho reduzido
Com mensagem propria

bth-navbar-pill-group

Grupo de filtros em formato de pilula, usado nos paineis de notificacoes e novidades.

  • O grupo aceita descricao, usada para acessibilidade.
  • No item, identificador e o que viaja no evento.
  • icone tem valor padrao cloud-question. Informe um icone proprio para cada filtro.
  • totalizador so aparece quando diferente de zero. O show-totalizador ja vem ligado; use show-totalizador="false" para esconder.
  • Emite navbarPillItemClicked com { identificador }. O estado ativo nao e automatico: o host controla o atributo ativo.
A descricao so fica visivel no item ativo. Nos demais ela vira o title do link, exibido como dica ao passar o mouse. E o comportamento esperado: a barra fica compacta e apenas o filtro atual mostra o rotulo.

Codigo

<bth-navbar-pill-group descricao="Filtros">
  <bth-navbar-pill-item identificador="todas" descricao="Todas" icone="format-list-bulleted" ativo></bth-navbar-pill-item>
  <bth-navbar-pill-item identificador="nao-lidas" descricao="Nao lidas" icone="email-mark-as-unread" totalizador="7"></bth-navbar-pill-item>
</bth-navbar-pill-group>

<script>
  document.addEventListener('navbarPillItemClicked', (event) => {
    console.log(event.detail.identificador);
  });
</script>

Resultado

Passe o mouse nos filtros inativos para ver a descricao como dica.

navbarPillItemClicked: aguardando

bth-selecao-contexto

Lista pesquisavel para o usuario escolher um contexto, como entidade ou time.

  • Propriedades buscar e selecionar sao funcoes, entao so podem ser definidas via JavaScript.
  • buscar retorna uma Promise com a lista de itens; o componente exibe o carregamento enquanto ela nao resolve.
  • Cada item e { id, descricao }, opcionalmente com complemento, imagemAvatar, icone, iconeStatus e iconeStatusTitle.
  • Atributo placeholder-pesquisa e slots cabecalho, sem_resultado e rodape.

Codigo

<bth-selecao-contexto id="contexto" placeholder-pesquisa="Qual entidade voce busca?">
  <h4 slot="cabecalho">Selecione a entidade que deseja acessar</h4>
  <div slot="rodape"><a href="#">Gerenciar contextos</a></div>
</bth-selecao-contexto>

<script>
  const contexto = document.getElementById('contexto');

  contexto.buscar = () => fetch('/api/entidades').then((resposta) => resposta.json());

  contexto.selecionar = (item) => {
    console.log('Selecionado', item.id, item.descricao);
  };
</script>

Resultado

Revise os termos da busca.

Ferramentas

Ocupam a barra de ferramentas do shell. Cada uma abaixo esta isolada em sua propria barra, sem nenhum bth-app na pagina.

bth-utilitarios

Lista de atalhos para outras areas do produto.

  • Propriedade utilitarios: array de { nome, icone, rota, possuiPermissao }.
  • Emite opcaoUtilitarioSelecionada ao escolher um item.

Codigo

<div class="barra">
  <bth-utilitarios id="utilitarios"></bth-utilitarios>
</div>

<script>
  const utilitarios = document.getElementById('utilitarios');

  utilitarios.utilitarios = [
    { nome: 'Relatorios', icone: 'file-chart', rota: '#relatorios', possuiPermissao: true },
    { nome: 'Importacoes', icone: 'database-import', rota: '#importacoes', possuiPermissao: true }
  ];

  utilitarios.addEventListener('opcaoUtilitarioSelecionada', (event) => {
    console.log(event.detail.nome, event.detail.rota);
  });
</script>

Resultado

opcaoUtilitarioSelecionada: aguardando

bth-ajuda

Atalho para a Central de Ajuda. E a ferramenta mais simples de usar fora do shell.

  • Atributo central-ajuda-home, opcional. Sem ele o componente busca o endereco em window.___bth.envs, populado pelo env.js.
  • Nao exige autenticacao e nao emite eventos.

Codigo

<div class="barra">
  <bth-ajuda central-ajuda-home="https://centraldeajuda.betha.com.br"></bth-ajuda>
</div>

Resultado

bth-conta-usuario

Dados do usuario logado e acesso a Central do Usuario.

  • Atributos usuario, nome e foto-url.
  • Atributo central-usuario-home, opcional, tambem resolvido pelo env.js.
  • Emite logout. Fora do shell, cabe ao host encerrar a sessao.

Codigo

<div class="barra">
  <bth-conta-usuario
    id="conta-usuario"
    usuario="lorem.ipsum"
    nome="Lorem Ipsum"
    foto-url="https://exemplo.com/foto.png"
    central-usuario-home="https://e-gov.betha.com.br/centraldousuario">
  </bth-conta-usuario>
</div>

<script>
  document
    .getElementById('conta-usuario')
    .addEventListener('logout', () => {
      // encerre a sessao da aplicacao
    });
</script>

Resultado

logout: aguardando

bth-suporte

Canais de atendimento e chat de suporte.

  • Atributo atendimento exibe os canais de contato.
  • Propriedade authorization para consultar as licencas do cliente.
  • Atributo blip-chat carrega o widget de chat externo. Nesse caso informe tambem a propriedade blipChatUserInfo com { id, nome, email }.
  • Renderiza um rotulo de texto ao lado do icone. Reserve espaco na barra.

Codigo

<div class="barra">
  <bth-suporte id="suporte" atendimento central-ajuda-home="https://centraldeajuda.betha.com.br"></bth-suporte>
</div>

<script>
  document.getElementById('suporte').authorization = authorization;
</script>

Resultado

bth-novidades

Lista de novidades do produto, com controle de lidas e nao lidas.

  • Propriedade authorization.
  • Atributo novidades-api, opcional, resolvido pelo env.js quando ausente.
  • Emite conteudoSinalizado quando ha novidades nao lidas. O contrato e exportado pelo pacote como ConteudoSinalizadoEvent.

Codigo

<div class="barra">
  <bth-novidades id="novidades" novidades-api="https://exemplo.betha.cloud/avisos"></bth-novidades>
</div>

<script>
  const novidades = document.getElementById('novidades');

  novidades.authorization = authorization;

  novidades.addEventListener('conteudoSinalizado', (event) => {
    console.log(event.detail.origem, event.detail.possui);
  });
</script>

Resultado

conteudoSinalizado: aguardando dados da API

bth-notificacoes

Notificacoes em tempo real, via REST e websocket.

  • Propriedade authorization.
  • Atributos notificacoes-api e notificacoes-ws, opcionais.
  • Emite conteudoSinalizado, novaNotificacao e novaNotificacaoComLink.

Codigo

<div class="barra">
  <bth-notificacoes
    id="notificacoes"
    notificacoes-api="https://exemplo.betha.cloud/notifications"
    notificacoes-ws="wss://exemplo.betha.cloud/notifications/v2/channel">
  </bth-notificacoes>
</div>

<script>
  const notificacoes = document.getElementById('notificacoes');

  notificacoes.authorization = authorization;

  notificacoes.addEventListener('novaNotificacaoComLink', (event) => {
    console.log(event.detail);
  });
</script>

Resultado

conteudoSinalizado: aguardando dados da API

Estrutura

Pecas do shell que tambem funcionam isoladas, para montar uma barra ou um painel proprio.

Ferramenta propria

As ferramentas acima sao composicoes sobre o bth-menu-ferramenta, que e generico: um icone que abre um painel lateral. Use-o para montar uma ferramenta propria, com conteudo definido pela aplicacao.

  • Atributos descricao e titulo-painel-lateral.
  • Slots menu_item_desktop, menu_item_mobile, menu_descricao_mobile e conteudo_painel_lateral.
  • O bth-menu-ferramenta-icone aceita icone, contador, status e mobile.

Codigo

<div class="barra">
  <bth-menu-ferramenta descricao="Meu recurso" titulo-painel-lateral="Meu recurso">
    <bth-menu-ferramenta-icone slot="menu_item_desktop" icone="cog" contador="3"></bth-menu-ferramenta-icone>
    <bth-menu-ferramenta-icone slot="menu_item_mobile" icone="cog" contador="3" mobile></bth-menu-ferramenta-icone>
    <span slot="menu_descricao_mobile">Meu recurso</span>

    <section slot="conteudo_painel_lateral">
      Conteudo definido pela aplicacao.
    </section>
  </bth-menu-ferramenta>
</div>

Resultado

Meu recurso

Conteudo definido inteiramente pelo host.

Painel lateral avulso

O painel funciona sozinho, sem ferramenta alguma. O host controla a abertura.

  • Propriedade show e atributo titulo.
  • Emite painelLateralShow ao abrir ou fechar.
  • Escuta bannerAlterado na janela para se reposicionar. Sem o shell esse evento nunca ocorre, e o painel mantem top: 40px.

Codigo

<bth-menu-painel-lateral id="painel" titulo="Painel avulso">
  <section>Conteudo do painel.</section>
</bth-menu-painel-lateral>

<script>
  document.getElementById('painel').show = true;
</script>

Resultado

painelLateralShow: aguardando

Este painel nao pertence a nenhuma ferramenta.

Itens de menu

O bth-menu-horizontal-item e o bth-menu-vertical-item sao apresentacionais. Dentro do shell quem monta a lista e o bth-app, a partir da propriedade opcoes; fora dele, o host escreve a lista e escuta os eventos de selecao.

  • O horizontal foi desenhado para fundo escuro, o vertical para fundo claro com largura fixa.
  • Emitem menuHorizontalSelecionado e menuVerticalSelecionado.
  • O estado ativo nao e automatico: o host controla o atributo ativo de cada item.

Codigo

<div class="barra">
  <bth-menu-horizontal-item identificador="visao-geral" descricao="Visao geral" ativo></bth-menu-horizontal-item>
  <bth-menu-horizontal-item identificador="relatorios" descricao="Relatorios" contador="4"></bth-menu-horizontal-item>
</div>

<div class="lista-vertical">
  <bth-menu-vertical-item identificador="inicio" descricao="Inicio" icone="home" ativo></bth-menu-vertical-item>
  <bth-menu-vertical-item identificador="cadastros" descricao="Cadastros" icone="folder" contador="12"></bth-menu-vertical-item>
</div>

<script>
  document.addEventListener('menuVerticalSelecionado', (event) => {
    console.log(event.detail.identificador, event.detail.identificadorPai);
  });
</script>

Resultado

menuHorizontalSelecionado: aguardando

menuVerticalSelecionado: aguardando

Fechamento dos paineis

As ferramentas escutam painelLateralShow na janela para fechar paineis sobrepostos. Dentro do shell quem coordena e o bth-app; fora dele, o proprio host dispara o evento.

Codigo

window.dispatchEvent(new CustomEvent('painelLateralShow', {
  detail: { show: false, fecharSobrepostos: true }
}));

Resultado

Abra qualquer painel desta pagina e use o botao.
